Code Refactor Rules

振る舞いを変えないと判断できる変換だけを行います。

ネスト削減はguard clauseを優先し、後続処理がある危険なケースは維持します。

変数名、関数名、副作用のある処理は勝手に変更しません。

ASTなしの簡易解析で扱えない複雑なコードは、整形中心に留めます。

対応ツール

JSON Formatter

Log Formatter
