Sensitive Logs Internal Code JSON Diffs

Built for local inspection

Readable Dev Tools exists because developers often need to format and inspect data that should not be pasted into remote services. AI tools often require sending data to external servers, which can be risky for production logs, internal code, JSON, stack traces, diffs, and config files.

Readable Dev Tools runs locally in your browser using static HTML, CSS, and JavaScript. It is designed for sensitive logs, internal code, JSON, stack traces, diffs, and config files that need to remain on your machine.

  • Format JSON, logs, stack traces, diffs, and minified code.
  • Refactor simple nested JavaScript and TypeScript-style code locally.
  • Use browser-only processing without external APIs.
  • No data leaves your browser.
