What Readable Dev Tools does not collect

Readable Dev Tools is designed for sensitive logs, JSON, stack traces, diffs, and code. Tool input is processed in browser memory and is not stored by this site.

  • We do not collect input data.
  • We do not store input data.
  • We do not send input data to servers.
  • We do not use APIs for processing.
  • We do not use localStorage, sessionStorage, IndexedDB, or cookies for tool input.
  • No data leaves your browser.

When you close the page, pasted tool input disappears because it is not written to browser storage by Readable Dev Tools.
